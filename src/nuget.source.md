# BuildMonitor

A build/CI monitor that runs in the system tray on Windows, macOS and Linux. Supports AppVeyor, Azure DevOps, Bitbucket Pipelines, GitHub Actions, GitLab CI, GoCD, Jenkins, Octopus Deploy, TeamCity and Travis CI, and hosts a local MCP server for AI assistants.

```
dotnet tool install -g BuildMonitor
buildmonitor
```

See https://github.com/SimonCropp/BuildMonitor for documentation.
